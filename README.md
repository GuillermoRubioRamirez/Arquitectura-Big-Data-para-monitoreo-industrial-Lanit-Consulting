## Infraestructura de Big Data para observabilidad industrial

Proyecto desarrollado en colaboración con LANIT para dotar a una planta industrial de una infraestructura de Big Data orientada a la ingesta, análisis y visualización en tiempo real de datos de red y sensórica.

El sistema se apoya en el stack ELK (Elasticsearch, Logstash, Kibana), MongoDB, Dash y Mosquitto (MQTT) para construir una plataforma de observabilidad robusta y escalable. Sobre esta base se implementaron modelos de detección de anomalías (K-means, Isolation Forest, One-Class SVM) para identificar patrones sospechosos en tráfico de red y comportamiento de servidores web, reforzando la ciberseguridad mediante detección proactiva de amenazas.

Adicionalmente, se desarrolló un algoritmo genético con PyGAD para optimizar la frecuencia de operación de compresores industriales, maximizando la eficiencia energética bajo restricciones físicas y operativas.

Todo ello se integró en dashboards interactivos que facilitan la toma de decisiones en entornos industriales.
